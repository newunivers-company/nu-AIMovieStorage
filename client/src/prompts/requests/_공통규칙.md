# 늘 지킬 것

## 품질 수식어를 쓰지 마세요

```
8k · 4k · masterpiece · best quality · ultra realistic · hyperrealistic
hyperdetailed · ultra detailed · highly detailed · award winning
```

요즘 모델은 **«극히 매력적인 이미지»로 추가 미세조정해서 나옵니다.** 그래서 가만두면
광고 사진이 됩니다. 위 말들은 **아무 정보도 주지 않으면서 그 편향을 더 밉니다.**
`masterpiece, best quality` 는 원래 애니 태그 체계에서 온 말이라 실사에는 맞지도 않습니다.

대신 **하나의 구체적인 촬영 상황**으로 바꿉니다. `professional product photography`
가 `high quality` 보다, `realistic skin texture` 가 `8K` 보다 훨씬 많은 정보를 줍니다.

**예외 하나 — GPT Image 는 `photorealistic` 을 직접 넣으라고 공식이 안내합니다.**
그 모델에서는 사진 모드를 켜는 스위치입니다.

## 사람이 나오면 피부를 적습니다

안 적으면 얼굴이 **플라스틱처럼 매끈하게** 나옵니다. 위와 같은 이유입니다.

```
natural visible pores, subtle uneven skin texture, fine peach fuzz
unretouched skin, no beauty retouching
fine lines around the eyes, slight redness on the cheeks and nose
```

얼굴이 큰 컷(클로즈업·바스트)이면 눈도 함께 적습니다. **캐치라이트가 없으면 죽은
눈이 됩니다** — 각막에 맺힌 광원의 반사라, 광원을 안 두면 안 생깁니다.

```
clear catchlight in both eyes, wet lower lid, visible eyelash roots
irregular hairline, a few flyaway strands
```

애니·3D·스톱모션 같은 **그림 계열에는 넣지 마세요.** 망칩니다.

## 광원을 지목합니다

「부드러운 조명」은 아무것도 정하지 않습니다. **어디에 있는 무슨 빛인지** 적습니다.
이것 하나로 광원 불일치와 죽은 눈이 같이 잡힙니다.

```
Large north-facing window on camera left, soft daylight
Small direct on-camera flash, hard frontal light
Soft overcast daylight, open shade, low contrast across the face
practical lights visible in the frame as the only sources
```

## 명령형 동사를 본문에 쓰지 마세요

「바꿔 · 지워 · 빼 · 늘려 · 추가해」가 본문에 들어가면, 일부 모델이 그 어투를 보고
**「새로 만들기」가 아니라 「편집·연장」 작업으로 오인합니다.**

| 이렇게 쓰면 | 이렇게 |
| --- | --- |
| 겉옷을 빨간색으로 바꿔 | 그녀는 빨간 겉옷을 입고 있다 |
| 배경에서 간판을 지워 | 배경은 간판이 없는 민 벽이다 |

## 금지 사항은 모델마다 자리가 다릅니다

| 모델 | 어디에 |
| --- | --- |
| Veo | 네거티브 칸. **「no」·「don't」를 쓰지 말고 명사만** 나열 |
| Kling · Seedance · LTX · GPT Image | 칸이 없습니다. 본문에 부정문으로 |
| **Runway · FLUX** | **부정문 자체가 안 통합니다.** 넣으면 오히려 그것이 나옵니다 |

부정문이 안 통하는 모델에서는 **「그게 없으면 대신 무엇이 보이나」**를 묻고 그걸 적습니다.

| 통하지 않음 | 이렇게 |
| --- | --- |
| `not blurry` | `sharp focus, high detail` |
| `No camera movement.` | `Locked camera. The camera remains still.` |
| `no text` | `clean surfaces, unmarked` |

## 한국어를 영문 칸에 넣지 마세요

영문 프롬프트에 한국어가 섞이면 생성기가 **그 부분만 통째로 무시합니다.**
사람이 적어 둔 설명·메모도 영문 칸에서는 **영어로 옮겨 적습니다.**

**예외는 태그와 이름뿐입니다** — `@냥이_001` 같은 그림 이름은 파일을 부르는 말이라
그대로 둡니다. 인물 이름도 잠금 문장에서는 그대로 씁니다.
