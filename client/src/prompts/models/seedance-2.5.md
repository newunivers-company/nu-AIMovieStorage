# Seedance 2.5 프롬프트 가이드

ByteDance 의 영상 생성 모델입니다. 한 번에 최대 30초, 소리까지 같이 만듭니다.
짧은 클립용 모델이 아니라 **30초짜리 한 편을 쓰는 모델**입니다. 프롬프트도 그렇게 씁니다.

## 이 모델이 잘하는 것 / 못하는 것

| 잘합니다 | 못합니다 |
| --- | --- |
| 30초 한 테이크를 끊지 않고 끌고 가기 | 화면 안 글자(간판·자막·로고). 글자는 후반에 얹으세요 |
| 대사·연기·감정 흐름이 있는 장면 | 손이 물건을 잡는 클로즈업 |
| 레퍼런스로 인물·의상 일관성 유지 | 빠른 액션에서 형태가 뭉개지는 현상(모핑) |
| 시간대별로 나눈 다단계 사건 | 소품 크기 추정 (책이 여행가방만 하게 나오는 식) |
| 카메라 지시대로 움직이기 | 물·천·입자 시뮬레이션의 정밀함 |
| 여러 언어의 대사와 입 모양 맞추기 | 목소리를 지정하지 않으면 억양이 제멋대로 정해집니다 |

- 생성이 길수록 뒤로 갈수록 인물·조명이 **드리프트**합니다. 잠금 문구로 눌러야 합니다.
- **Seedance 2.0 용 프롬프트를 그대로 옮기지 마세요.** 1초 단위로 컷을 쪼개는 방식은
  2.5 에서 잘 듣지 않습니다. 호흡을 길게 잡습니다.

## 프롬프트 구조 — 여섯 칸, 이 순서로

`주체` → `동작·사건` → `장면·환경` → `비주얼 스타일` → `카메라 움직임·컷` → `오디오`

**앞의 둘만 필수**입니다. 나머지는 통제하고 싶은 것만 채우고 비웁니다.
빈 칸을 억지로 채우면 지시끼리 충돌해 결과가 흐려집니다.

### 간단한 클립 (한 상황, 5~10초)

두세 문장이면 충분합니다. 길게 쓴다고 좋아지지 않습니다. **길이보다 명확함입니다.**

```
비 내리는 골목에서 낡은 코트를 입은 중년 남자가 우산을 접고 문 앞에 선다.
젖은 아스팔트에 간판 불빛이 번진다. 카메라는 어깨 높이에서 천천히 밀고 들어간다.
<빗소리, 우산 접히는 소리> 음악 없음.
```

### 30초 한 편 (여러 단계, 컷 전환)

블록으로 나눠 씁니다. 아래 순서가 드리프트를 가장 잘 막습니다.

1. **전역 스타일** — 장르, 색보정, 필름 질감, 제외 항목
2. **로그라인** — 한 줄로 무슨 일이 일어나는지
3. **인물** — 얼굴·머리·체형·의상. 레퍼런스가 있으면 번호로 지정
4. **장소·소품** — 인물과 분리해서. 장소가 애매하면 컷마다 딴 곳이 됩니다
5. **첫 프레임과 블로킹** — 시작 위치와 보는 방향
6. **시간대별 진행** — 아래 시간 표기 규칙
7. **광학** — 렌즈 화각, 카메라 높이, 핸드헬드/달리
8. **물리** — 천·머리카락·액체가 어떻게 움직이는지
9. **조명** — 주광 하나 + 보조광. 광원의 이유를 적습니다
10. **오디오** — 앰비언스, 효과음, 제외 항목
11. **고정 항목** — 마지막에 한 번 더 못 박습니다

## 칸을 빠뜨리면 **정해진 방식으로** 망가집니다

위 블록을 그냥 «있으면 좋은 것» 으로 읽지 마세요. 하나를 비우면 **그 칸에 딸린 실패가
정확히 그대로** 나옵니다. 어느 칸을 빠뜨렸는지 결과만 보고도 알 수 있습니다.

| 빠뜨린 칸 | 이렇게 망가집니다 |
| --- | --- |
| **장소·소품** 이 막연함 | 컷이 바뀔 때마다 딴 곳이 됩니다. 「카페」 만 적으면 컷마다 다른 카페입니다 |
| **광학**(렌즈·높이·움직임) 미지정 | 그 컷이 통째로 실패합니다. 컷마다 세 개를 다 적어야 합니다 |
| **첫 프레임과 블로킹** 없음 | 모델이 동작을 **시작하지 못합니다.** 서 있을 자리가 없으니까요 |
| 좌우 **화면 방향**이 컷마다 뒤집힘 | 다중 컷이 통째로 흐트러집니다. 한 번 정한 좌우를 끝까지 지킵니다 |
| 조명 대신 **색보정**에 기댐 | 후반에 고칠 생각으로 빛을 안 적으면, 빛이 없는 그림이 나옵니다 |

**대부분의 프롬프트는 한 번만 돌립니다.** 그래서 「돌려 보고 고치기」 가 아니라
**처음부터 칸을 다 채우는** 쪽이 맞습니다.

## 인물 자리는 화면 백분율로

여러 명이 나오는 컷에서 누가 어디 서는지를 **숫자로** 못 박을 수 있습니다.

```
THE WOMAN 화면 왼쪽에 앉아 있다, x 42%, y 44%.
THE MAN 화면 오른쪽에 서 있다, x 71%, y 38%.
```

말로만 「왼쪽에」 라고 하면 컷마다 조금씩 옮겨 갑니다. 백분율은 안 흔들립니다.
우리 앱은 구도잡기에서 이 값을 **이미 알고 있습니다** — 3D 자리를 화면에 내리면 그대로 나옵니다.

## 컷마다 화질을 가르기

한 편 안에서 「극영화 화면」 과 「휴대폰으로 찍은 화면」 을 섞을 때 씁니다.
대괄호 이름표를 만들어 두고 구간마다 어느 쪽인지 적습니다.

```
[FILM] 잘 다듬은 현대 디지털 시네마.
[REPORTER CAM] 2000년대 초 싸구려 휴대폰 화질, VHS 압축, 뭉개진 블록, 탁한 색.
화질 저하는 REPORTER CAM 구간에만 적용한다.
```

## 물성은 «무엇이 어떻게 움직이는가» 로

재질 이름만 적으면 모델이 기본 물리를 씁니다. **그 재질이 어떻게 움직이는지**를 적으세요.

```
지폐는 섬유결이 보이고 가장자리가 닳아 접힌 자국이 있으며 살짝 말려 있다.
띠가 끊어지면 낱장이 흩어지며 저마다 다른 공기 흐름을 타고 떨어진다.
```

순간마다의 물리도 시점으로 못 박습니다.

```
0.0s 너울이 밀려온다. 1.2s 첫 파도가 앞 바위에 부딪히고 물보라가 화면 높이의 12%까지 튄다.
2.4s 돌풍, 머리카락이 한 번 들렸다가 가라앉는다.
```

## 시간 표기

30초를 통째로 맡기지 말고 구간을 나눕니다.

- 정수 초로만 씁니다. `0-8s:` `8-20s:` `20-30s:`
- **구간 사이에 빈 틈을 두지 않습니다.**
- 한 구간에 사건 하나. 두 개 넣으면 둘 다 흐려집니다.
- 순간을 못 박을 때는 시점으로: `13.2s 에 오른쪽 눈에서 눈물 한 줄기가 떨어진다`
- 컷 전환은 구간 끝에 `하드 컷` 이라고 명시합니다.

```
0-8s: 넓은 화면. 그녀가 창가에 서 있다. 카메라 고정. 하드 컷
8-20s: 미디엄 투샷. 남자가 들어와 말한다. 천천히 밀어 들어간다. 하드 컷
20-30s: 클로즈업. 그녀가 고개를 돌린다. 카메라 고정.
```

## 문체

**태그 나열이 아니라 서술문입니다.** 쉼표로 형용사를 늘어놓지 마세요.
누가 무엇을 하는지 문장으로 씁니다. 다만 소리와 화면 글자만은 괄호 문법을 씁니다.

| 기호 | 용도 | 예 |
| --- | --- | --- |
| `（ ）` | 음악 | `（잔잔한 피아노가 장면 아래로 흐른다）` |
| `< >` | 효과음 | `<멀리서 종이 울린다>` |
| `{ }` | 대사 | `{다녀왔어.}` |
| `【 】` | 화면 자막 | `【제1장】` |

- **대사의 톤과 언어는 괄호 밖에 먼저 씁니다.**
  `사용 언어는 한국어. 그녀가 낮고 떨리는 목소리로 말한다: {괜찮아.}`
- 목소리를 지정하지 않으면 참조 이미지를 보고 모델이 임의로 정합니다. 억양까지 적으세요.
- 소리 요소는 종류별로 다른 괄호에 넣습니다. 섞으면 잘못 배치됩니다.

## 레퍼런스 지정

최대 50개 — 이미지 30, 영상 10, 오디오 10.

- `@Image 1` `@Video 2` `@Audio 1` 처럼 번호를 붙여 부릅니다.
- **그 레퍼런스에서 무엇을 쓸지 반드시 좁힙니다.**
  `@Image 1 은 얼굴과 재킷만 정한다. 배경 하늘과 주차된 차는 쓰지 않는다.`
- 같은 요소를 두 레퍼런스로 정의하지 마세요. 모델이 어느 쪽인지 못 정합니다.
- 여러 각도가 같은 물건이면 그렇게 말합니다. `세 장 모두 같은 램프다`
- 등장 인원은 숫자로 못 박습니다. `이 두 사람만 존재한다` — 안 그러면 사람이 늘어납니다.
- 인물은 대문자·고정 호칭으로 부릅니다. `THE MAN` `THE WOMAN`
- 안정적으로 유지되는 피사체는 대략 **1~8개**까지입니다.

## 출력 제약

| 항목 | 값 |
| --- | --- |
| 길이 | 4~30초, 1초 단위. 기본 5초 |
| 해상도 | 네이티브는 480p / 720p. 1080p·4K 옵션은 **업스케일** |
| 비율 | 16:9 · 9:16 · 1:1 · 4:3 · 3:4 · 21:9 · adaptive |
| 오디오 | 생성 여부를 켜고 끕니다. 편집·연장 모드에서는 기본 켜짐 |
| 시드 | 고정 가능. `-1` 이면 매번 다르게 |
| 모드 | 텍스트→영상 · 이미지→영상 · 첫·끝 프레임 · 레퍼런스 · 영상 편집 · 영상 연장 |

- 편집 모드에서는 비율이 입력 소스에 고정됩니다.
- fps 는 파라미터로 노출되지 않습니다. 프롬프트에 `24fps 느낌` 처럼 질감으로만 씁니다.
- 최종 납품용 화질이 필요하면 뽑은 뒤 따로 업스케일하는 편이 낫습니다.

## 네거티브 프롬프트

**별도의 네거티브 입력란이 없습니다.** 빼고 싶은 것은 본문에 그대로 씁니다.

- 잘 듣습니다: `음악 없음` `자막 없음` `로고와 워터마크 없음` `점프컷 없음` `화면 글자 없음`
- 스타일 부정도 강하게 듣습니다: `골든아워 아님, 차갑고 임상적인 실내광`
  `3D 렌더 아님, 플라스틱 CG 광택 아님`
- 애매한 부정은 실패합니다. `대사 최소화` → 안 됩니다. `대사 없음` → 됩니다.
- 부정문은 문서 맨 위(전역 스타일)와 맨 아래(오디오)에 모아 둡니다.

## 잘 듣는 표현

| 이렇게 | 이러지 말고 |
| --- | --- |
| `84도 화각의 클래식 와이드` | `와이드 샷` |
| `얼굴에서 4미터, 조리개 개방, 얕은 초점` | `클로즈업` |
| `무거운 스튜디오 달리로 느리고 매끄럽게, 흔들림 없음` | `시네마틱하게` |
| `13.2s 에 그녀가 걷기 시작한다` | `중간쯤에 걷는다` |
| `창밖 오후 햇빛이 왼쪽 뺨에 떨어진다` | `아름다운 조명` |
| `발이 바닥에 닿고 체중이 실린다` | (생략 — 인물이 떠다닙니다) |
| `지폐 한 장 한 장이 흩날린다, 굳은 덩어리 아님` | `돈이 날린다` |
| `정확히 네 명, 다섯 명이 되지 않는다` | `여러 명` |
| `비는 30초 내내 같은 밀도와 방향으로 내린다` | `비가 온다` |

카메라 동작은 이름으로 부릅니다. `달리 인` `푸시 인` `휩 팬` `오빗` `랙 포커스` `로우 앵글` `탑다운` `트래킹`.

## 피할 것

- **서로 싸우는 지시.** `핸드헬드 다큐멘터리` + `고정된 대칭 구도` → 결과가 뭉갭니다.
- **장소를 뭉뚱그리기.** 다중 컷이 컷마다 다른 공간으로 흘러가는 1순위 원인입니다.
- **위치 없는 이동.** `그녀가 방을 가로지른다` 대신 어디서 어디로인지 씁니다.
- **1초짜리 빠른 컷 나열.** 2.5 는 이 방식을 거부합니다.
- **형용사 도배.** 길이는 정확도를 만들지 않습니다.

## 드리프트를 막는 마무리 블록

30초짜리에는 프롬프트 끝에 이 블록을 붙입니다.

```
고정 항목:
두 인물은 모든 컷에서 같은 얼굴, 같은 의상, 같은 젖은 상태를 유지한다.
좌우 위치 관계는 모든 컷에서 바뀌지 않는다.
차량에 어떤 상표도 없다.
음악 없음, 내레이션 없음, 자막 없음.
```

인물이 오래 나오면 2~3컷마다 얼굴과 의상을 다시 한 줄로 확인시킵니다.
