# Midjourney 프롬프트 가이드

**짧은 서술구를 쉼표로 끊어 늘어놓고, 끝에 매개변수를 붙이는** 모델입니다.
문장으로 길게 풀어 쓰면 오히려 흐려집니다. 앞에 놓인 말이 강하게 걸립니다.

## 글의 모양

```
[주제와 모습], [의상·재질], [배경], [조명], [카메라·렌즈], [화풍] --ar 2:3 --s 250 --no text
```

- **영문으로 씁니다.** 한국어는 해석이 흔들립니다.
- 60 낱말 안쪽. 길수록 각 낱말의 힘이 나눠집니다.
- 가장 중요한 것을 **맨 앞**에. 인물이면 인물, 장소면 장소가 첫 구입니다.
- 「beautiful」 「amazing」 같은 평가어는 아무것도 정하지 못합니다. 무엇이 어떻게
  생겼는지를 적으세요.
- 품질 주문어(`8k`, `masterpiece`, `ultra detailed`)는 넣지 않습니다.

## 매개변수

| 매개변수 | 쓰임 |
|---|---|
| `--ar 2:3` | 인물 전신. 세로로 길게 |
| `--ar 16:9` | 장소·풍경 |
| `--ar 1:1` | 물건 한 점 |
| `--s 0 ~ 1000` | 화풍을 얼마나 얹을지. 기준 시트는 **250 이하**로 낮게 |
| `--no A, B` | 나오면 안 되는 것. **별도 네거티브 칸이 없습니다** |
| `--seed N` | 같은 값을 주면 비슷한 결과. 판을 이어 뽑을 때 |
| `--chaos N` | 결과를 흩뜨립니다. 기준 시트에는 쓰지 마세요 |

**판 번호(`--v`, `--niji`)는 적지 마세요.** 판이 오르면 틀린 값이 되고,
그때 무엇이 잘못됐는지 찾기 어렵습니다. 판은 생성기 설정에서 고릅니다.

## 가중치

`keyword::2` 로 앞 구의 힘을 올립니다. `::` 는 구를 나누는 표시이기도 해서,
`red hair::2 blue coat::1` 은 «빨간 머리를 두 배로, 파란 코트는 그대로» 입니다.

한 프롬프트에 두세 개까지만. 남발하면 서로 상쇄되어 아무것도 안 걸립니다.

## 네거티브

`--no` 하나뿐입니다. 쉼표로 잇습니다.

```
--no text, watermark, signature, extra limbs, blurry
```

부정문을 본문에 쓰지 마세요(`no hat` 이라고 쓰면 모자를 그립니다).
빼야 할 것은 반드시 `--no` 로 보냅니다.

## 기준 시트를 뽑을 때

- 배경은 `flat neutral grey #808080 studio backdrop` 으로 못 박습니다.
- 조명은 `even studio lighting, no cast shadow`.
- `character sheet`, `multiple views`, `turnaround` 같은 말은 **넣지 마세요** —
  이 앱은 시트를 따로 합성합니다. 여기서는 또렷한 한 장이 필요합니다.

## 마지막 점검

- 영문인가, 60 낱말 안쪽인가
- 가장 중요한 것이 맨 앞에 있는가
- `--ar` 이 대상에 맞는가 (인물 2:3 / 장소 16:9 / 물건 1:1)
- 빼야 할 것이 본문이 아니라 `--no` 에 있는가
- 판 번호와 품질 주문어가 남아 있지 않은가
