# Kling 3.0 프롬프트 가이드

Kling 3.0 은 **연출을 읽는 영상 모델**입니다. 이미지 모델처럼 «무엇이 보이는가» 를 나열하면 결과가 밋밋해집니다. **«카메라가 어떻게 움직이고, 인물이 무엇을 하고, 무슨 소리가 나는가»** 를 시나리오처럼 적습니다.

---

## 1. 잘하는 것과 못하는 것

| 잘합니다 | 못합니다 |
| --- | --- |
| 시네마틱 카메라 언어 해석 (트래킹·돌리·POV·랙 포커스) | 한 컷 안에 여러 카메라 움직임을 동시에 지시하기 |
| 한 클립 안 여러 컷(멀티컷) 연결과 공간 연속성 유지 | 요소가 많은 복잡한 판타지·마법 장면 |
| 인물 정체성 유지, 인물 3인 이상 구분 | 긴 대사에서의 립싱크 정확도 |
| 감정 연기·표정 | 화면 안 문자(자막·간판·로고) 정확한 표기 |
| 네이티브 오디오(대사·효과음·환경음) 동시 생성 | 첫 프레임 구도를 텍스트만으로 정확히 잡기 (레퍼런스 이미지 권장) |
| 한국어 대사를 한국어로 말합니다 | **연기가 과장됩니다**(6절) · 인물 교체·대사 누락 등 간헐적 흔들림 |

**핵심 성향** — 움직임의 강도를 낮출수록 안정적입니다. 느린 카메라, 단순한 동작이 사실적으로 나옵니다.

---

## 2. 규격

| 항목 | 값 |
| --- | --- |
| 길이 | 3 ~ 15 초 (초 단위 지정, 기본 5초) |
| 비율 | 16:9 · 9:16 · 1:1 |
| 해상도 | 표준 720p / 프로 1080p. 일부 API 제공처는 4K(3840×2160) 모드를 별도로 제공합니다 |
| 오디오 | 네이티브 오디오 켜기/끄기 선택. 멀티컷을 쓰면 기본으로 켜집니다 |
| 입력 | 텍스트→영상, 이미지→영상, 첫 프레임+끝 프레임, 참조 이미지/요소 |
| 멀티컷 | 한 생성 안에 최대 5~6컷 (제공처에 따라 다름), 합계가 전체 길이를 넘지 않게 |
| 프롬프트 길이 제한 | 제공처마다 다릅니다 (컷당 500자 제한인 곳, 1500자인 곳). **컷당 400자 안쪽**으로 쓰면 안전합니다 |

비율은 이미지→영상일 때 입력 이미지 비율을 자동으로 따라갑니다.

---

## 3. 프롬프트 구조 — 이 순서로 씁니다

```
① 장면(공간·시간·빛) → ② 인물(정체성·의상) → ③ 동작(순서대로)
→ ④ 카메라(움직임·샷 크기) → ⑤ 소리·톤·스타일
```

다만 **카메라 지시는 앞쪽에 두는 편이 더 잘 듣습니다.** 짧은 단일 컷이라면 카메라를 첫 문장에 놓고 시작합니다.

```
느린 돌리 인. 비 내리는 새벽 골목, 젖은 아스팔트에 네온이 번진다.
검정 트렌치코트를 입은 30대 여자가 우산을 접고 문 앞에 선다.
손끝이 손잡이에 닿는 순간 멈춘다. 카메라는 어깨 높이에서 그대로 따라간다.
빗소리, 멀리 지나가는 차 소리. 필름 그레인, 차가운 청록 톤.
```

**규칙**

- 동작은 **시간 순서대로** 씁니다. 「~하고 나서」, 「그 순간」, 「멈춘 뒤」 같은 연결어가 타이밍을 잡아 줍니다.
- 인물은 **처음 등장할 때 외형을 확정**하고, 그 뒤로는 같은 이름·같은 표현으로 부릅니다.
- 대명사(그, 그녀, 그것)는 쓰지 않습니다. 인물이 뒤바뀝니다.

---

## 4. 길이와 문체

- **서술문**으로 씁니다. 태그 나열(`cinematic, 8k, masterpiece, highly detailed`)은 효과가 약합니다.
- 다만 **대사와 인물 라벨은 태그 형식**을 씁니다. 서술문 + 부분 태그의 혼합이 가장 잘 듣습니다.
- 길이는 **논리적으로 정돈된 150~200 단어**가 적정선입니다. 짧고 모호한 20 단어보다 낫습니다. 길이 자체가 문제가 아니라 순서가 뒤엉킨 것이 문제입니다.
- 한 문장에 한 가지 사건만 담습니다. 쉼표로 무한히 잇지 않습니다.

---

## 5. 카메라 표현

**구체적인 촬영 용어를 씁니다.** 「움직인다」, 「간다」 같은 일반 동사는 모델에게 아무 정보도 주지 않습니다.

| 잘 듣는 표현 | 쓰임 |
| --- | --- |
| 느린 돌리 인 / 돌리 아웃 | 긴장 조성, 이탈 |
| 트래킹 샷, 뒤에서 따라가는 트래킹 | 인물 이동 |
| 핸드헬드, 어깨 카메라의 미세한 흔들림 | 다큐·현장감 |
| 크레인 샷, 로우 앵글, 하이 앵글 | 규모·권력 관계 |
| 랙 포커스, 스냅 포커스 | 주의 이동 |
| 휩 팬, 크래시 줌 | 충격·전환 |
| 360도 오빗, 슬로우 오빗 | 대상 소개 |
| 익스트림 클로즈업 / 미디엄 샷 / 와이드 설정 샷 | 샷 크기 |
| POV, 프로필 샷, 매크로 클로즈업 | 시점 |

**한 컷에 카메라 움직임은 하나.** 「줌 인하면서 팬하고 동시에 상승」 같은 지시는 결과가 예측 불가능해집니다. 여러 움직임이 필요하면 컷을 나눕니다.

## 6. 대사와 소리

네이티브 오디오를 켜면 대사·효과음·환경음이 함께 생성됩니다. 대사는 **화자·톤을 라벨로 묶어** 씁니다.

```
[인물 A: 형사, 낮고 눌린 목소리]: "이제 그만하죠."
[인물 B: 용의자, 목소리가 갈라지며]: "무슨 말인지 모르겠는데요."
```

- 톤 지시(「속삭이듯」, 「화내며 소리치는」, 「목소리가 떨리며」)를 붙이면 연기가 살아납니다.
- 대사는 짧게 끊습니다. 긴 문장은 립싱크가 흔들립니다.
- 효과음·환경음도 적습니다. 소리를 비워 두면 화면만 남고 밋밋해집니다. 예: `SFX: 낮은 드론음, 멀리 사이렌`
- 15초 안에 담기는 대사량은 많지 않습니다. 인물당 한두 마디로 잡습니다.

### 한국어 대사 — 잘 말합니다. 다만 연기가 과장됩니다

 **실사용 기준입니다.**

2.6 공식 오디오 가이드에는 「중국어·영어만 소리로 내고 나머지는 영어로 번역해
발음한다」고 적혀 있습니다. **3.0 은 다릅니다** — 한국어를 한국어로 말합니다.
2.6 의 제약을 3.0 에 그대로 옮겨 적지 마세요(2026-09-18 에 제가 그렇게 잘못 적었습니다).

실제 문제는 언어가 아니라 **연기의 세기**입니다. 톤 라벨을 그대로 주면
필요 이상으로 크게 연기합니다. 그래서 **한 단계 낮춰** 적습니다.

| 이렇게 적으면 | 이렇게 바꿉니다 |
| --- | --- |
| 화내며 소리치는 | 낮게 눌러 말하는, 턱에 힘이 들어간 |
| 울먹이며 | 목이 살짝 잠긴, 눈에 물기만 |
| 놀라서 | 숨이 한 박자 멎었다가 |
| 활짝 웃으며 | 입꼬리만 올라간, 눈가가 접히는 |

- **톤 라벨은 하나만.** 「화내며 떨리는 목소리로 다급하게」처럼 겹쳐 주면
  셋을 다 하려다 과장됩니다.
- **강도 말을 먼저 붙입니다** — `slight`, `subtle`, `barely perceptible`.
  Kling 은 기본값이 이미 세서, 안 적으면 늘 큰 쪽으로 갑니다.
- 그래도 과하면 **톤 라벨을 아예 빼고** 행동만 적으세요. 얼굴은 대사가 알아서 합니다.

### 차례를 안 정하면 한 사람이 계속 말합니다

공식 경고입니다. 화자가 바뀌는 자리에 **연결어를 반드시** 넣으세요.

```
[인물 A: 형사, 낮고 눌린 목소리]: "이제 그만하죠."
Immediately, as the speaker switches,
[인물 B: 용의자, 목소리가 갈라지며]: "무슨 말인지 모르겠는데요."
```

그 밖의 공식 규칙 넷.

1. **라벨은 고유하고 일관되게.** 대명사나 비슷한 다른 말로 부르지 마세요.
2. **행동을 먼저 쓰고 대사를 붙입니다** — 그래야 누가 말했는지 고정됩니다.
3. **인물마다 다른 톤 라벨**을 줍니다.
4. **2인 대화까지** 권장. 셋 이상은 성능이 떨어집니다.

대사·노래 장면은 **10초** 쪽이 안정적입니다.

### 목소리 연기 트리거 워드 (공식)

라벨 안에 그대로 넣습니다.

`Whispering` · `Softly Speaking` · `Clearly Speaking` · `Excitedly Speaking` ·
`Complaining` · `Sighing` · `Gently Speaking` · `Hoarse Voice` · `Deep Voice` ·
`Fast Talking` · `Slow Talking` · `Answering` · `Arguing` · `Shouting` ·
`Discussing` · `Crying / Sobbing` · `Screaming` · `Laughing / Chuckling` ·
`Reciting` · `Monologue` · `Narration / Voiceover`

### 2.5 이하는 무음입니다

네이티브 오디오는 **2.6 부터**입니다. 그 아래 판은 소리를 아예 안 만듭니다 —
대사를 적어도 입만 움직이거나 무시됩니다. 립싱크는 별도 기능으로 붙입니다.
영상에 얼굴이 여럿이면 API 가 얼굴을 골라 입힐 수 있습니다.

## 7. 멀티컷 (AI 디렉터)

한 생성 안에서 여러 컷을 이어 붙일 수 있고, 공간 연속성은 모델이 유지합니다.

```
컷 1 (0~3초): 로우 앵글 와이드. 터널 끝 역광, 선수들 실루엣.
컷 2 (3~7초): 핸드헬드, 뒤에서 따라가는 트래킹.
   [인물 A: 주장, 단호하게]: "가자."
컷 3 (7~12초): 와이드. 조명이 쏟아지는 경기장으로 뛰어나간다.
```

- 컷마다 **번호와 초 구간**을 적습니다. 구간을 빼면 편집 타이밍이 무너집니다.
- 인물 묘사는 **모든 컷에서 동일한 표현**으로 반복합니다. 컷마다 다르게 쓰면 다른 사람이 됩니다.
- 15초에 6컷을 밀어 넣으면 컷당 2~3초라 사건 하나씩만 들어갑니다. 3~4컷이 안정적입니다.

## 8. 네거티브 프롬프트

**받습니다.** Kling 은 본문과 분리된 네거티브 프롬프트 칸을 별도로 둡니다. 다만 일부 API 제공처는 이 항목을 노출하지 않습니다. 그런 경우에만 본문 끝에 회피 문구를 붙입니다.

- **쉼표로 끊은 명사·짧은 구**로 씁니다. 문장으로 쓰지 않습니다.
- 「~없이」, 「~하지 마라」 같은 부정 표현을 **본문에** 넣지 않습니다. 본문의 부정어는 오히려 그 대상을 불러옵니다.

**기본 세트**

```
흐릿함, 깜빡임, 일그러진 얼굴, 뒤틀린 팔다리, 손가락 개수 오류,
질감 뭉개짐, 형태 변형, 저화질, 워터마크, 자막, 화면 속 글자
```

**동작이 있는 장면에 추가**

```
발이 미끄러지듯 끌림, 지면과 어긋난 발, 카메라 흔들림, 갑작스러운 속도 변화
```

**인물 유지가 중요한 장면에 추가**

```
얼굴 바뀜, 의상 바뀜, 머리 모양 바뀜, 인물 추가 등장
```

## 9. 잘 듣는 표현 · 피할 표현

| 이렇게 | 이러지 않게 |
| --- | --- |
| `느린 돌리 인, 어깨 높이` | `카메라가 움직인다` |
| `[인물 A: 형사]: "..."` | `그가 말한다: "..."` |
| `우산을 접고, 그 다음 문 손잡이를 잡는다` | `문 앞에서 이것저것 한다` |
| `젖은 아스팔트에 번지는 네온, 차가운 청록 톤` | `아름다운, 놀라운, 최고 품질의` |
| `빗소리, 멀리 지나가는 차 소리` | (소리 언급 없음) |
| `30대 여자, 검정 트렌치코트, 짧은 단발` (매 컷 동일) | `그녀` / 컷마다 다른 묘사 |
| 회피 항목은 네거티브 칸에 | `글자가 없이, 손가락 오류 없이` 를 본문에 |
| 카메라 움직임 하나 | `줌하면서 팬하고 상승` |

**추가로 피할 것**

- 이미지 모델용 품질 태그(`8k, masterpiece, ultra detailed`) — 영상 품질에 거의 영향이 없습니다.
- 화면에 글자를 띄우라는 지시 — 정확히 나오지 않습니다. 자막은 후반 작업으로 넣습니다.
- 15초 안에 담기지 않는 서사 — 사건 하나, 감정 변화 하나로 좁힙니다.

## 10. 체크리스트

프롬프트를 넘기기 전에 확인합니다.

1. 카메라 움직임이 **구체적 용어**로 한 개 적혀 있는가
2. 인물 외형이 **처음에 확정**되고 이후 **같은 표현**으로 반복되는가
3. 동작이 **시간 순서**로 적혀 있는가
4. 대명사 대신 **인물 라벨**을 쓰는가
5. **소리**가 한 줄이라도 적혀 있는가
6. 멀티컷이면 **컷 번호와 초 구간**이 있는가
7. 회피 항목이 **네거티브 칸**에 명사 나열로 들어갔는가
8. 길이(3~15초) 안에 담기는 분량인가
